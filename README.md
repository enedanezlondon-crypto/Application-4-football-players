# PLAYFORM | אימונים לשחקני כדורגל

אפליקציית אימונים אישית לשחקני כדורגל. בוחרים עמדה, רמת משחק, מטרה ומספר אימונים שבועיים כדי לקבל תוכנית וספריית תרגילים מותאמות.

## הפעלה מקומית

```sh
npm install
npm run dev
```

## Build ופריסה

```sh
npm run build
```

תיקיית הפרסום היא `dist`. הקובץ `render.yaml` מגדיר פריסה אוטומטית כ־Static Site ב־Render.

## יכולות

- תוכניות אימון לשוערים, מגינים, קשרים, כנפיים וחלוצים.
- התאמת תרגילים לפי רמת משחק, מטרה ומספר אימונים שבועי.
- מעבר תחנות וסימון אימון שהושלם.
- ספריית תרגילים עם חיפוש וסינון לפי קטגוריה.
- גרף שבועי, סיכום דקות ויומן התקדמות.
- שמירת הפרופיל וההתקדמות בדפדפן באמצעות `localStorage`.

המידע נשמר בדפדפן הנוכחי ואינו מסתנכרן בין מכשירים. התרגילים הם הצעה כללית ואינם תחליף להנחיית מאמן או איש מקצוע.
